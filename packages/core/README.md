# `@deploy-crab/core`

Node 侧共享的运行逻辑。使用 tsdown 构建 ESM、`.d.ts` 和 source maps；类型声明通过独立声明转换生成，完整类型检查由 Turbo 的 `check-types` 前置任务完成。

应用开发时通过包名读取这里的构建产物，Turbo 负责先构建并在依赖变化后重启应用。生产构建把 core 的运行代码直接打入应用，交付时不需要额外安装这个私有工作区包。

开发数据目录固定为仓库根目录的 `.deploy-crab/`（从模块位置推算），正式运行固定为 `~/.deploy-crab/`。调用方可传入覆盖路径（server 来自启动参数 `--data-dir`），绝对路径直接使用，相对路径按启动工作目录解析。

本包使用 Node 文件系统 API，不能直接导入浏览器应用。前后端共享的类型、校验或纯函数应放入不含 Node 依赖的工作区包。
